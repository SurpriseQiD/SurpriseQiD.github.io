    1. DID 在识别什么

    双重差分关注的是“处理组相对对照组，在政策后多变化了多少”：

    Yit=αi+γt+βDit+εit Y_{it}=\alpha_i+\gamma_t+\beta D_{it}+\varepsilon_{it} Yit​=αi​+γt​+βDit​+εit​

    其中 β\betaβ 是核心参数，解释依赖平行趋势假设。

    2. 平行趋势不能只靠口头陈述

    建议至少做三步：

    • 政策前趋势图（处理组 vs 对照组）；
    • 事件研究中的政策前 lead 系数检验；
    • 更换样本窗口与控制组做稳健性对照。

    3. Python 示例（双向固定效应）

    from linearmodels.panel import PanelOLS
import statsmodels.api as sm

panel = df.set_index(["unit", "time"]).sort_index()
panel["const"] = 1

mod = PanelOLS.from_formula(
    "y ~ 1 + did + x1 + x2 + EntityEffects + TimeEffects",
    data=panel,
)
res = mod.fit(cov_type="clustered", cluster_entity=True)
print(res)

    4. 事件研究法（动态效应）

    构造相对政策时点 k=t−Tik=t-T_ik=t−Ti​，回归：

    Yit=αi+γt+∑k≠−1βk1{eventtime=k}+εit Y_{it}=\alpha_i+\gamma_t+\sum_{k \neq -1}\beta_k 1\{event_time=k\}+\varepsilon_{it} Yit​=αi​+γt​+k=−1∑​βk​1{eventt​ime=k}+εit​
    • 省略 k=−1k=-1k=−1 作为基期；
    • 政策前 βk\beta_kβk​ 应接近 0；
    • 政策后 βk\beta_kβk​ 展示动态影响路径。

    5. 实务陷阱

    • 处理时点错位导致“伪动态效应”；
    • 标准误未聚类导致显著性夸大；
    • 处理组与对照组构成差异过大。

    结论应建立在“识别假设 + 诊断图 + 稳健性”的组合证据上。

    6. 一张 2×2 表

    政策前，处理组与对照组的结果都是 101010。政策后，处理组是 161616，对照组是 121212。双重差分是

    (16−10)−(12−10)=4. (16-10)-(12-10)=4. (16−10)−(12−10)=4.

    处理组自己上升了 666，其中 222 是对照组也有的变化，多出来的 444 才是 β\betaβ 想解释的部分。若政策前处理组已经是 131313、对照组是 101010，两组起点就不同，上面的减法仍然能算出一个数，但那个数混合了原有差距。事件研究里政策前的系数，就是在检查这种起点差会不会在更早的时期已经出现。
