计量经济学：面板数据 FE/RE 与 Hausman 检验

比较固定效应与随机效应的识别前提、解释边界与模型选择逻辑。

    1. FE 与 RE 的核心区别

    • FE（固定效应）：允许个体不随时间变化的不可观测因素与解释变量相关。
    • RE（随机效应）：要求个体效应与解释变量不相关，条件更强但效率更高。

    因此，模型选择本质上是“你是否相信 RE 的外生性前提”。

    2. 模型形式

    固定效应：

    Yit=αi+βXit+γt+uit Y_{it}=\alpha_i+\beta X_{it}+\gamma_t+u_{it} Yit​=αi​+βXit​+γt​+uit​

    随机效应：

    Yit=α+βXit+ci+uit,Cov(ci,Xit)=0 Y_{it}=\alpha+\beta X_{it}+c_i+u_{it}, \quad Cov(c_i, X_{it})=0 Yit​=α+βXit​+ci​+uit​,Cov(ci​,Xit​)=0

    3. Python 示例

    from linearmodels.panel import PanelOLS, RandomEffects

panel = df.set_index(["firm", "year"]).sort_index()

fe = PanelOLS.from_formula(
    "y ~ 1 + x1 + x2 + EntityEffects + TimeEffects",
    data=panel,
).fit(cov_type="clustered", cluster_entity=True)

re = RandomEffects.from_formula(
    "y ~ 1 + x1 + x2",
    data=panel,
).fit(cov_type="robust")

print(fe)
print(re)

    4. Hausman 思路

    Hausman 检验比较 FE 与 RE 估计差异是否系统性显著。若显著，通常倾向 FE。

    实践上，不应机械依赖单一检验：

    • 先做经济学判断（RE 条件是否可信）；
    • 再用 Hausman 作为统计补充；
    • 同时报告 FE 与 RE 的稳健性差异。

    5. 结论表达建议

    • 明确“识别依赖的不可观测异质性假设”；
    • 若用 FE，说明无法识别时间不变变量系数；
    • 若用 RE，说明其外生性前提与潜在风险。

    模型不是终点，可信识别才是终点。

    6. 固定效应在减掉什么

    两个人、两期。甲的结果是 1,31,31,3，解释变量是 0,10,10,1。乙的结果是 10,1410,1410,14，解释变量是 0,10,10,1。甲的个体均值是 222，乙的是 121212。组内变换之后，甲变成 −1,1-1,1−1,1，乙变成 −2,2-2,2−2,2；解释变量两边都变成 −0.5,0.5-0.5,0.5−0.5,0.5。

    斜率只用这些去掉均值之后的变化来估计。甲、乙谁的水平更高，不再进入斜率。这也是固定效应不能识别性别、籍贯这类两期内不变的变量：它们减完均值是 0。随机效应不把这些水平全部减掉，所以效率可能更高，但要求那些没减掉的个体差异不和解释变量相关。Hausman 检验比较的就是这两种斜率差得远不远；差得远，说明随机效应留下的那部分和解释变量有关，不能当外生。
