    1. 何时用合成控制

    当只有一个或少数处理对象，且传统 DID 的平行趋势较难成立时，SCM 常更有解释力。
    核心思想是：用对照组加权组合出一个“最像处理组处理前路径”的合成对象。

    2. 基本形式

    设处理组处理前结果向量为 X1X_1X1​，对照组矩阵为 X0X_0X0​，权重向量为 WWW：

    W∗=arg⁡min⁡W(X1−X0W)′V(X1−X0W) W^*=\arg\min_W (X_1-X_0W)'V(X_1-X_0W) W∗=argWmin​(X1​−X0​W)′V(X1​−X0​W)

    约束：wj≥0w_j\ge 0wj​≥0 且 ∑jwj=1\sum_j w_j=1∑j​wj​=1。
    处理后效应估计为：

    τ^t=Y1t−∑jwj∗Yjt \hat\tau_t = Y_{1t} - \sum_j w_j^* Y_{jt} τ^t​=Y1t​−j∑​wj∗​Yjt​

    3. Python 最小实现思路

    import numpy as np
import cvxpy as cp

# X1: (k, 1), X0: (k, J)
w = cp.Variable(X0.shape[1])
objective = cp.Minimize(cp.sum_squares(X1.flatten() - X0 @ w))
constraints = [w >= 0, cp.sum(w) == 1]
prob = cp.Problem(objective, constraints)
prob.solve()

w_star = w.value
synthetic_y = Y0 @ w_star  # Y0: (T, J)
effect = Y1 - synthetic_y   # Y1: (T,)

    4. 推断与稳健性

    SCM 常用安慰剂（placebo）推断：

    1. 把每个对照组依次当作“伪处理组”。
    2. 重复构造其合成对照。
    3. 比较真实处理效应与伪效应分布位置。

    此外建议报告：

    1. 处理前拟合误差（RMSPE）。
    2. 剔除关键供体后的 leave-one-out 稳健性。
    3. 不同预测变量集合下的结果稳定性。

    5. 常见误区

    1. 处理前拟合很差却直接解释处理后差异。
    2. 忽略供体池选择对结果的结构性影响。
    3. 把 SCM 当作“自动因果工具”，不讨论制度背景。

    合成控制法的说服力，来自“处理前拟合质量 + 安慰剂对比 + 制度叙事一致性”。

    6. 两个供体怎么配权重

    处理地区政策前两年的结果是 5,75,75,7。供体 A 是 4,64,64,6，供体 B 是 6,86,86,8。取权重 0.50.50.5 和 0.50.50.5，合成路径是 5,75,75,7，和政策前完全重合。政策后处理地区是 101010，合成对照若是 888，差值 222 就是这一期的估计。

    权重不是回归里随便的正负系数。它们通常限制在和为 111 且非负，这样合成对照是供体的加权平均，而不是外推到谁都没出现过的水平。把处理地区和政策前明明对不上的供体硬配在一起，政策前的差距会留到政策后，差值就不是处理效应。安慰剂是把从未处理的供体轮流当作“处理对象”再估一遍：若真处理地区的差值并不比这些假处理更大，这个 222 就没有特殊之处。
