    PyTorch深度学习开发完全指南

    PyTorch是当前最流行的深度学习框架之一，以其动态计算图和易用性著称。本指南将全面介绍PyTorch的使用。

    1. 环境配置与安装

    1.1 安装PyTorch

    # 根据你的CUDA版本选择
# CPU版本
pip install torch torchvision torchaudio

# CUDA 11.8版本
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 使用conda安装
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia

    2. 张量是什么

    张量是带形状的数组，也是自动求导的载体。一个形状为 (n,d)(n, d)(n,d) 的 float32 张量，既可以是一批样本的特征，也可以是某一层的权重。设备（CPU 或 GPU）和数据类型要在运算前对齐，否则加法会直接报错，而不是悄悄给出错的梯度。

    3. 自动求导在算什么

    对标量损失 LLL 调用 backward() 时，PyTorch 沿计算图把 ∂L/∂w\partial L/\partial w∂L/∂w 累加到 w.grad。梯度默认累加，所以每个优化步之前要 zero_grad()。漏掉这一步，下一步用的是两次梯度之和，更新方向就偏了。

    4. 一个最小回归

    设 y=3x+εy = 3x + \varepsilony=3x+ε，用一条没有偏置的线性层拟合斜率。一次训练步是：前向得到 y^\hat yy^​，损失取均方误差，反传，再 optimizer.step()。若学习率过大，损失会在头几步上升；若数据没有标准化，xxx 的量级会直接进到梯度里。先把这四步跑通，再谈更深的网络。
