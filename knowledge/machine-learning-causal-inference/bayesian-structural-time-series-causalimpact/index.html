贝叶斯结构时间序列（BSTS）与 CausalImpact

从反事实预测视角讲清 BSTS 的因果评估逻辑，并提供 Python 版本实现路径。

    1. 适用场景

    当无法做随机实验，但有稳定历史序列与可用对照指标时，BSTS 是强有力的政策评估工具。
    典型问题：某次投放/改版上线后，指标到底增加了多少。

    2. 方法本质

    步骤分两层：

    1. 在干预前区间拟合“正常世界”生成机制。
    2. 在干预后预测反事实路径，与真实值比较得到增量。

    可写作：

    τt=ytobs−ytcf \tau_t = y_t^{obs} - y_t^{cf} τt​=ytobs​−ytcf​

    其中 ytcfy_t^{cf}ytcf​ 是无干预时的后验预测。

    3. Python 实现思路

    import pandas as pd
from orbit.models import DLT

# y: 被解释指标, X: 对照变量
train = df.loc[:"2025-06-30"]
test = df.loc["2025-07-01":]

model = DLT(
    response_col="y",
    date_col="ds",
    regressor_col=["x1", "x2", "x3"],
    seasonality=7,
)

model.fit(train)
cf = model.predict(test)  # 反事实预测
impact = test["y"].values - cf["prediction"].values
print(impact.mean())

    4. 关键假设

    1. 干预后对照变量不受干预反向影响。
    2. 干预前关系在干预后可外推（结构稳定）。
    3. 无同步重大冲击与干预同向混杂。

    5. 常见误区

    1. 把受干预影响的变量当作对照输入。
    2. 干预前窗口太短，先验主导后验。
    3. 只报平均影响，不报不确定区间。

    BSTS 的优势是把“预测不确定性”显式纳入因果结论，非常适合业务决策沟通。

    6. 反事实就是一条预测

    干预前四周的结果是 10,10,11,1110,10,11,1110,10,11,11。用这段历史给出的干预后预测是 111111，区间是 [10,12][10,12][10,12]。实际观测是 141414。141414 落在区间外面，点估计的差异是 333。

    若干预前只有一个点，预测几乎由先验决定，区间会宽到把 141414 也包括进去，差异就不再说明问题。对照序列若在干预时点和结果一起跳，模型会把那次跳跃学进预测，141414 看起来就不异常。报告时要同时给出预测、区间和实际值，而不是只给一个“提升了百分之多少”。
